⏱ 角度一：下方空间分析

核心问题：玉米还能跌多少？价格是否已经"跌不动"？即使基本面不支持上涨，如果下方空间已经封闭，是否可以卖出看跌期权赚取权利金？

一、下方空间评估框架

下方空间分析关注的是"还能跌多少"，而非"会不会涨"。玉米当前价格2265元/吨已接近新季集港成本线2250-2300元/吨，成本支撑较强。但9-10月新粮集中上市、替代品供应充裕、需求疲软三重压力下，下方空间尚未完全封闭。

下方空间评估需要回答三个核心问题：

  • 问题1：当前价格距离成本线有多远？成本支撑是否足够坚固？
  • 问题2：新粮上市压力能将价格压到什么位置？政策托底在哪里？
  • 问题3：如果破位，下方还有多少空间？最大跌幅能到多少？

二、成本支撑评估——"铁底"在哪里？

1. 成本构成与当前价格关系

2. 关键发现

  • 当前期货价格2265元/吨已基本触及新季集港成本线2250-2300元/吨，成本支撑开始生效
  • 新季种植成本同比上涨约10%，主要因地租上涨：黑龙江涨12.5%-25%，吉林涨17%-57%
  • 农户惜售线相应上移：去年0.75元/斤（折2100元/吨），新季预计0.90元/斤（折2250-2300元/吨）
  • 糙米集港成本2280-2300元/吨与玉米新季成本高度重合，形成"政策替代天花板"
  • 进口玉米（巴西）到岸成本2150-2200元/吨略低于国内，但配额限制下进口量有限（1-6月仅100.61万吨）
  • 成本端结论：2250-2300元/吨是核心成本支撑区，2100元/吨是农户惜售"铁底"

3. 通俗解读

玉米的成本就像一道"阶梯"。最底下一级是农户的惜售线2100元/吨——跌到这个位置，农民宁可把粮食囤着也不卖。往上一级是新季集港成本2250-2300元/吨——这是贸易商收粮加上烘干、运输的总成本，跌破了贸易商就亏本。

现在期货价格2265元/吨，已经站在了新季成本线上。这意味着成本支撑开始发挥作用。但有一个特殊因素：糙米的成本也是2280-2300元/吨，和玉米成本几乎一样。这就形成了一个"天花板"——如果玉米价格涨过2300，饲料厂就会改用糙米，压制玉米涨不动；但如果玉米跌破2250，糙米也没有价格优势了，替代需求会回落，反而支撑玉米。

2. 上市压力下的价格测试路径

  • 第一步测试：新季集港成本2250-2300元/吨（9-10月上市初期）
  • 贸易商和深加工在0.8元/斤（折2240元/吨）以下有建库意愿，形成第一道支撑
  • 第二步测试：农户惜售线2100-2150元/吨（如果上市压力超预期）
  • 农户在0.75元/斤（折2100元/吨）会惜售，这是"铁底"
  • 政策托底：中储粮收储预期，去年2月才大规模收储推动价格上涨，今年可能提前
  • 判断：2100-2200元/吨是半年内底部成本区间，跌破2100概率较低（<15%）

3. 卖Put结论

谨慎关注，建议等待9-10月新粮上市压力释放后再考虑。成本支撑较强但新粮上市压力未释放，波动率偏低对卖方不利。需要等待以下条件满足后再考虑：

  • ☐ 条件1：新粮上市压力释放，价格测试2250-2300成本线企稳
  • ☐ 条件2：深加工开机率回升，淀粉库存停止累积
  • ☐ 条件3：饲料企业玉米库存天数回升（当前25.37天，同比-14.35%）
  • ☐ 条件4：中储粮收储政策明确落地

如果以上条件满足3个以上，可考虑卖出C2701或C2703合约行权价2150-2200的看跌期权。远月合约（C2705收于2350元）升水较大，卖Put安全边际更高，但需严控仓位，单笔风险不超过总资金的5%。

4. 通俗解读

下方空间分析就像判断一个皮球从桌上掉下来还能弹多深。玉米现在已经在桌沿了——价格2265元，几乎贴着新季成本线2250-2300元。从成本角度看，确实"快跌不动了"。

但有一个"重锤"还没落下来——9-10月新粮集中上市。就像秋收时粮食堆满仓库，短期供应大增，价格可能再被压一压。最坏情况可能测试2100-2150元（农户惜售线），但跌破2100元的概率很低，因为农民宁可囤着也不卖。

还有一个"安全网"——中储粮收储。去年2月政府大规模收储推动价格上涨，今年可能提前行动。所以，等9-10月上市压力释放完，就是考虑卖Put的好时机。

  • 成本支撑已到位（唯一亮点）：新季成本2250-2300元+农户惜售线2100元构成双底
  • 供应端全面宽松：新季丰产（+400-700万吨）+进口增加+替代品充裕
  • 需求端全面疲软：深加工亏损扩大（山东-199元/吨）+饲料需求受替代挤压

  • 库存信号矛盾：港口去库但淀粉累积，饲料企业无补库意愿

做多建议：观望为主。当前反转条件远不具备，"跌不动"不等于"要涨"。需要等待以下信号出现后再考虑做多：

  • ☐ 信号1：新粮上市压力释放，价格测试成本线企稳
  • ☐ 信号2：深加工利润修复，淀粉库存停止累积
  • ☐ 信号3：小麦-玉米价差扩大至150元以上（替代优势消退）
  • ☐ 信号4：中储粮明确大规模收储政策
  • ☐ 信号5：饲料企业玉米库存天数回升

4. 通俗解读

底部反转分析就像判断一个病人能不能下床走路。玉米现在的情况是：身体底子还行（成本支撑），但浑身没劲（需求疲软），而且还有人压着不让动（替代品压制）。

具体来说：

  • "身体底子"：新季种植成本涨了10%，2250-2300元的成本线像一副"拐杖"，撑着不让价格跌太深
  • "浑身没劲"：饲料厂不买粮（库存同比-14.35%），深加工亏得厉害（山东每吨亏199元），没有人愿意提价收粮
  • "有人压着"：小麦比玉米只贵62元，饲料厂用小麦更划算；糙米成本2280-2300元和玉米差不多；进口高粱大麦源源不断

结论：玉米现在"跌不动"（成本支撑），但也"涨不起"（需求疲软+替代压制）。要等到9-10月新粮上市压力释放完，且看到深加工利润修复、饲料厂开始补库，才是考虑做多的时机。

📖 通俗总结

给老年投资者的白话总结：

玉米现在就像秋收前的一袋粮食，价格已经跌到了农民的成本线附近（2265元 vs 成本2250-2300元）。再往下跌，农民就不卖了，贸易商也愿意收，所以下方空间有限。

但9-10月新粮就要上市了，就像仓库马上要堆满新粮，短期价格可能再被压一压。最坏可能跌到2100-2150元，但跌破2100元的可能性很小（农民宁可囤着也不卖）。

至于能不能涨起来？目前看难。因为饲料厂不买粮（有更便宜的小麦、糙米替代），深加工亏得厉害，没有人愿意提价收粮。要等到新粮上市压力释放完，且看到饲料厂开始补库、深加工不再亏损，才是考虑做多的时机。

建议：现在以观望为主。等9-10月新粮上市压力释放后，可以考虑卖出看跌期权（行权价2150-2200）赚权利金，因为成本支撑很强，价格很难跌破2100元。但做多暂时不具备条件。
