⏱ 角度一：下方空间分析

核心问题：烧碱还能跌多少？价格是否已经"跌不动"？即使基本面不支持上涨，如果下方空间已经封闭，是否可以卖出看跌期权赚取权利金？

一、为什么8月的1800-1900底部被跌破了？

⚠ 复盘教训：8月15日分析判断"下方空间基本封闭（7/10）"，理由是成本约束+检修收缩+采购价上调。但此后三大利空超预期：(1) 库存不降反升（同比+33.5%，8月时预期去化）；(2) 需求塌方（氧化铝现货同比较-12.5%→压价至560元新低、出口低迷、内需弱势）；(3) 新产能推迟投放（130万吨）。教训：高库存品种的"成本支撑"会被库存压力击穿，成本线只提供"缓冲垫"而非"铁底"。

2. 关键发现：液氯联产收益是新的"底"所在

  • 氯碱联产机制：每生产1吨烧碱（折百）约伴生0.885吨氯产品，山东液氯均价已上行至300元/吨，每吨烧碱可获得约265元联产收益抵扣
  • 西部现金流成本1845元扣除液氯收益后约1580元——期货1608元恰好跌入该区域，成本约束首次真正开始生效
  • 当前山东氯碱企业综合毛利仍有134元/吨（正值），说明行业尚未出现现金流断裂，高成本企业靠液氯收益勉强维持，缺乏自发性减产动力
  • 山东32%现货均价610元（折百1906）仍在西部现金流成本1845之上，期货1608较现货深贴水约300元（-16%）——期货已提前定价现货跌向1650-1750
  • 成本端结论：期货下方真正的"铁底"在1500-1550元——全行业（含液氯收益）综合现金亏损线，触及将触发自发性减产；当前1608距铁底仅约4-7%，下方空间已大幅压缩

3. 通俗解读

烧碱8月的"底部"1800-1900元被跌穿了，因为仓库里的货太多了（比去年同期多33%）、下游氧化铝厂不断压价、新的生产线还在投产。但这一轮下跌有个新情况：期货价格1608元已经跌到了"最便宜的厂家连氯气收益算上、刚好不亏现金"的位置（约1580-1650元）。

烧碱是"氯碱联产"——生产烧碱必然同时产出氯气。氯气现在能卖300元/吨，就像开饭店的炒菜钱亏了但卖汤水还赚钱，综合算账还没到关门的程度。所以真正的"铁底"要再往下挪：到1500-1550元，那时候连卖氯气的钱都补不上窟窿，厂家会真正自发减产停产。当前1608元距离铁底只剩4-7%的空间了。

3. 卖Put结论

可关注远月深虚值Put——本分析首次给出比8月更积极的评级。理由：与8月（期货尚在1800-1900上方、下方是成本"悬空区"）不同，当前期货已跌入综合现金成本区，且铁底1500-1550明确。策略：

  • ☐ 标的：SH2705远月合约，行权价1500-1550元/吨的深虚值看跌期权（全行业含氯现金亏损线，触及概率10-15%）
  • ☐ 时机：当前即可分批建仓；若期货反弹至1700-1750（现货收敛区）而隐含波动率回落，权利金更优
  • ☐ 风控：单笔仓位≤5%；密切跟踪液氯价格（跌破200元/吨则综合成本线上移，减仓）；跟踪库存（同比增速收窄至+10%以内为安全信号）

4. 通俗解读

现在卖看跌期权（赌"跌不到更深处"）比8月更有底气：8月时价格还在半空中、下面没有接应；现在价格已经掉到"厂家账本上刚好不亏现金"的地板上了，再往下的空间只有4-7%，而且那下面是"全行业亏现金→自发停产"的保底层。

选行权价1500-1550，就是赌"烧碱跌不穿全行业的现金亏损线"。历史上没有哪个行业能在全行业亏现金的状态下久待——要么减产、要么涨价，价格就会回头。唯一要盯防的是氯气价格：如果氯气从300元跌下来，厂家的"地板"就要往下挪，那时要减仓。

👴 老人总结：烧碱价格已经跌到"厂家卖碱亏一点、靠卖氯气补回来、刚好不关门"的账本线上了。8月份说的那个底被太多的存货压破了，现在的新底要看到1500-1550——那里连卖氯气的钱都补不上窟窿，厂家只能停炉子。从现在的价钱到新底只剩一小截，往下摔的空间不大了，所以现在可以考虑卖远处的"看跌期权"赚点小钱，但别贪多。

4. 通俗解读

烧碱价格已经到了历史最低的价位区，这是好消息；但仓库里积压的货还比去年多三分之一，最大的买家（氧化铝厂）还在压价，新的生产线还在点火，这是坏消息。所以虽然"贵的地方"到了，"涨的时候"还没到。

反转要等三件事凑齐：一是仓库的货开始变少（现在还在变多）；二是氧化铝厂停止压价（他们自己的行情也在跌）；三是春天检修潮（2027年4-5月，厂家集中检修，货少了价格自然抬头）。这三件事发生前，价格大概率在1550-1750之间来回磨底。

策略上可以"小仓试探+耐心等待"：现在用不超过两成的仓位在1600-1650慢慢捡便宜货，亏了就认（跌破1500止损）；等库存拐点出现再加到主力仓位。机构也说了——反弹是脉冲，别指望一口气涨回去。

👴 老人总结：烧碱跌到历史最便宜了，但便宜不等于马上涨。仓库的货还堆着三分之一，买家还在砍价，就像集市快散场时菜贩子手里的菜——已经够便宜了，可大家还在等更便宜。真正涨价要等三件事：仓库的货变少、氧化铝厂不砍价了、明年春天厂家集中检修。等到这些信号出现再加大买货的量，现在只用小钱慢慢捡。
